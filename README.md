# Harbor & Thread — Responsive Clothing Store UI

Files:
- index.html — responsive landing page
- feedback.html — second-page feedback form
- styles.css — responsive desktop/tablet/mobile styling
- script.js — sidebar, search, budget filtering, pagination UI, and form validation

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For best results, use a local server such as VS Code Live Server.

The design is inspired by the reference image but uses original branding and layout details.
